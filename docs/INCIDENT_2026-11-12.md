# Scheduled delivery failure and audience correction

Run: [43174573571](https://github.com/mrazizbeksafarov/NovaGrants/actions/runs/43174573571),
2026-11-12, 12:20 Tashkent. Baseline commit `3136cdd`.

## Database failure

Telegram acknowledged the reminder and four-card digest. The digest journal was
`delivery_sent`, so delivery was known and automatic resending was blocked.
The run then failed while saving the Stanford entry:

```
23505: duplicate key value violates unique constraint posted_grants_url_key
Key (url)=(https://engineering.stanford.edu/SURF) already exists.
```

The historical row had `status=duplicate`, the official Stanford URL, and an
aggregator article in `url_key`. The writer checked the incoming official
`url_key` but did not locate the same URL under the old source-based key.
Its fallback repeated the same incomplete lookup. The earlier isolated journal
probe exercised journal storage, not this legacy grant-row collision.

The writer now resolves both unique identities. It promotes an unposted URL
owner with a conditional update, preserves already-posted rows, and retains both
keys when separate legacy rows own the key and URL. A unique-key insertion race
re-reads both identities with bounded retries. Exact posted URLs also participate
in deduplication independently of historical keys. No historical row is deleted.

Live recovery re-applied only saved database operations. The legacy URL row was
promoted and the journal became `delivery_done`. Zero Telegram sends occurred.

## Content correction

Stanford's [official requirements](https://engineering.stanford.edu/SURF) require
current enrolment at a US college/university and CPT or Pre-Completion OPT
authorization for international students. Students studying outside the US are
ineligible. This programme should not have been selected for an audience applying
from Uzbekistan. The earlier quote check established that a quote existed in
source text; it did not sufficiently enforce the audience's study location.

The [existing channel post 587](https://t.me/Nova_Grants/587) was edited in place:
Stanford removed, heading/navigation changed to three opportunities, copied
nationality removed, dates rendered once. MCW's training length and exclusions,
deposit, and the two forums' application fees were corrected from official pages.
Telegram's successful edit response was checked; the original journal retains
its delivery intent plus a correction record, rather than rewriting delivery
history. No replacement channel post was sent.

Sources: [MCW](https://mcwglobal.org/young-leaders-fellowship-2027/),
[World Impact Forum](https://thegiic.org/world-impact-forum-2027/),
[London Youth Diplomacy Forum](https://youthdiplomaticacademy.org/upcoming-event/fully-funded-london-youth-diplomacy-forum-2027).

The editor now explicitly excludes foreign-residence/enrolment prerequisites,
and a deterministic gate catches explicit English/Uzbek foreign-enrolment
requirements even when nationality is unrestricted. Translation leaks and the
repeated Uzbekistan-citizenship phrase trigger editorial repair/retry. These
checks cover the observed errors, not every possible wording or source omission.
